Description / 描述

  More Info adds compact, real-time information panels to your HUD and map — everything appears on hover. Potion drop tracker, card rarity odds, unknown room encounter rates,
  and shop price preview with relic discount support.

  在 HUD 和地图上添加紧凑的实时信息面板 —— 全部悬停显示。药水掉落追踪、卡牌稀有度概率、
  问号房间遭遇概率、含遗物折扣的商店价格预览。

Installation / 安装方式

  Installation: Extract the archive. Place the more_info folder into your game's mods/ directory.
  Launch Slay the Spire 2. The mod loads automatically.
  安装：解压后将 more_info 文件夹放入游戏 mods/ 目录，启动游戏即可。

Main Features / 主要特点

  - Inspired by the More Info mod from Slay the Spire 1.
  - 受到杀戮尖塔1 更多信息显示 mod 启发。

  Potion Drop Tracker
  - Persistent indicator on the top bar showing current potion drop chance.
  - Hover to expand: elite combat drop probability + cumulative odds over the next 2/3/4/5 combats.
  药水掉落追踪
  - 顶部栏常驻指示器，显示当前药水掉落概率。
  - 悬停展开：精英战掉落概率 + 未来 2/3/4/5 场至少掉落一次的累计概率。

  Card Rarity Drop Odds
  - Top-bar indicator showing rare card current drop odds.
  - Hover to see a Regular vs Elite combat rarity breakdown (Rare / Uncommon / Common).
  卡牌稀有度掉落概率
  - 顶部栏指示器，显示稀有卡当前掉落概率。
  - 悬停查看普通战斗 vs 精英战斗各稀有度（稀有/罕见/普通）概率分布。

  Unknown Room Encounter Odds
  - Hover any unvisited ? node on the map to see current encounter type probabilities.
  - Event / Monster / Elite / Treasure / Shop — each with a distinct colour label.
  - Relic modifiers factored in — Juzu Bracelet, Golden Compass.
  问号房间遭遇概率
  - 悬停地图上未到达的 ? 节点，查看当前各遭遇类型概率。
  - 事件/怪物/精英/宝箱/商店 —— 每种用独立颜色标注。
  - 含遗物修正 —— 佛珠手链，金罗盘。

  Shop Price Preview
  - Hover any unvisited shop node on the map to preview the full price table.
  - Relics / Cards / Potions broken down by Common / Uncommon / Rare with price ranges.
  - Membership Card (×0.5) and The Courier (×0.8) discounts applied automatically.
  - Prices grey out when you can't afford them with current gold.
  商店价格预览
  - 悬停地图上未到达的商店节点，预览完整价格表。
  - 遗物/卡牌/药水按普通/罕见/稀有分列，显示价格区间。
  - 会员卡（×0.5）与送货员（×0.8）折扣自动生效。
  - 当前金币不够时价格灰色显示。

  - Language auto-follows the game setting (中文 / English).
  - 语言自动跟随游戏设置。

Requirements / 依赖

  - No other mods required. Fully standalone.
  - 无需其他 Mod，完全独立运行。
