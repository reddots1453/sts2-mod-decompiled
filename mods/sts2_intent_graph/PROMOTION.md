Description / 描述

  Intent Graph visualises the full enemy AI state machine when you hover over any monster during combat.
  See every possible move, branch probability, repetition limit, and conditional transition — all rendered
  as a clean, icon-only graph in the classic STS1 "Intents Graph" mod style.

  悬停任意怪物即可查看其完整 AI 意图状态机。所有可能的行动、分支概率、连续使用次数上限和条件转移一目了然，
  以经典 STS1 "Intents Graph" mod 风格的纯图标图表呈现。

Installation / 安装方式

  Installation: Extract the archive. Place the intent_graph folder into your game's mods/ directory.
  Launch Slay the Spire 2. The mod loads automatically.
  安装：解压后将 intent_graph 文件夹放入游戏 mods/ 目录，启动游戏即可。

Main Features / 主要特点

  - Inspired by the Intent Graph mod from Slay the Spire 1.
  - Hover any monster to see its full intent state machine.
  - Shows all reachable states with intent icons and damage numbers (multi-hit shown as N×M).
  - Random branches display probability percentages and structural rules (≤1 / ≤N / ×1 / CD:N).
  - Conditional branches show readable condition labels (e.g. "Position 1", "HP<50%").
  - Yellow arrows for normal transitions, red arrows for conditional branches.
  - Multi-phase bosses shown as separate phase boxes with red transition arrows.
  - Baked automatically —— automatically adapts to ascension and game version changes.
  - Language auto-follows the game setting (中文 / English).

  - 受到杀戮尖塔1 mod Intent Graph启发。
  - 悬停任意怪物查看完整意图状态机。
  - 显示所有可达状态，含意图图标与伤害数值（多段攻击显示为 N×M）。
  - 随机分支显示概率百分比与结构规则（≤1 / ≤N / ×1 / CD:N）。
  - 条件分支以可读标签标注（如"1号位"、"HP<50%"）。
  - 黄色箭头常规转移，红色箭头条件分支。
  - 多阶段 Boss 以独立阶段框 + 红色阶段转移箭头显示。
  - 自动预烘焙——自动随进阶和版本更新变化。
  - 语言自动跟随游戏设置(中文 / English)。

Requirements / 依赖

  - No other mods required. Fully standalone.
  - 无需其他 Mod，完全独立运行。
